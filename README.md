## Описание
Пакет `mobiletariff` предназначен для расчёта стоимости мобильной связи (минуты и интернет), применения скидок и формирования отчёта.

## Структура
- `pkg/mobiletariff` — собственный пакет с логикой расчётов.
- `cmd/app/main.go` — точка входа с использованием внешних пакетов (`fatih/color`, `google/uuid`).
